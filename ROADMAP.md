# Roadmap

## V1: fixture-forged crawls

- Deterministic local fixture inputs.
- Queue and dedupe primitives.
- Robots/politeness configuration from fixtures.
- Markdown/JSON writers.
- Replayable manifests.

## Later, only with explicit safety review

- Optional live fetch command with clear flags and rate limits.
- Sitemap fixture ingestion.
- Additional output adapters.
- Manifest replay/diff command.
- Library ergonomics for agent pipelines.

## Non-goals

- Hidden network calls.
- Browser automation.
- Credential scraping.
- Telemetry.
